# Charts merge by same music within a source, but only by same shape across sources

Within one source, charts with the same music (same lyrics, same chords relative to the key) are one arrangement whatever their key or format, and the site shows the best one: readable over as-is, fewer pages, PDF over Word/Google Doc, newest; a hand-fixed chart always wins. Across sources, arrangements merge only when their charts are the same shape (look the same on the page, key aside), and the result carries every source's tag ("YFM · ASE") and every key each source has.

The obvious rule, merging same music everywhere, was rejected because each team wants the sheet they're used to: a YFM member picking *Living Hope* expects YFM's layout, not a tidier chart from MM. Same shape is the line where nothing a player sees changes, so merging there only removes clutter (ASE's key exports already sit byte-identical in YFM) and adds keys.

## Consequences

- Popular songs can appear once per source in search, ordered by a fixed source priority (YFM first).
- As-is charts can't be read, so their shape is compared by page image.
- When an arrangement has a chart in the chosen key, that chart is used as it is; only otherwise is the best chart transposed.
